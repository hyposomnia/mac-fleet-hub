# iOS 会话详情原生化功能与验收清单

本次迁移面向 iPhone 与 iPad App 中的会话详情。目标是一次覆盖当前功能，由开发侧完成回归后集中进行用户验收。范围依据 2026-10-17 当前工作树源码，包含未提交改动；历史 UAT 文档仅作线索，实际行为以当前代码为准。清单经过一个不继承聊天历史的子 agent 独立审计，并由主 agent 与前一版清单逐项核对。

开发可以按模块实施；交付候选版必须包含完整功能链路与检查结果。以下检查项都是迁移要求，不代表已经完成实现或验证。

## 上一版清单的补充与修正

1. **释放与恢复写入需要独立验收。** “支持跨端同步”不能覆盖只读切换、待审批释放、控制快照失效和恢复写入。
2. **Markdown 不等于完整正文。** 代码块行号与复制、结构化任务/Git 状态卡、浏览器评论和批注引用都需单列。
3. **离线待发与服务端队列不同。** 前者依赖页面或运行时存活，编辑会取消；后者持久化在服务端，有状态版本和操作能力。不能暗示离线点击后杀 App 仍可靠发送。
4. **批注不是只有选中文本和输入评论。** 必须保留多来源、来源歧义、原文变化、查看原文、再次注释、持久草稿和正确的会话绑定。
5. **附件上传上限是 20 MiB。** 文件管理上传的 512 MB 是另一条链路；附件失败目前显示失败及移除，不将“一键重试”当作现成能力。
6. **MCP 包含外部 URL 授权。** 表单渲染之外还要覆盖跳出 App、返回和完成或拒绝。
7. **问答有密码字段和多选协议差异。** 敏感字段不进入普通调试日志；DSH 自定义答案与选中项不能错误合并。
8. **阅读状态与预览存在联动。** 文件预览时不能简单把后台更新的会话全部视为已读；手动未读须尊重当前跨端规则。
9. **草稿恢复范围需要明确。** 当前已有草稿持久化不代表所有上传二进制、问答临时输入及全部进程状态都能在强杀重启后恢复。原生恢复矩阵需要逐类验证并说明范围。
10. **已有原生 UI 也可能依赖 Web DOM。** 模型/权限弹层和 Sub Agent 等已有原生投影，不等于底层业务已脱离网页；正文 DOM 停用前必须解除这类隐式依赖。
11. **链接带有来源 Mac 的网络语义。** 普通外链经 `/host-view` 打开，本地链接带设备与 cwd；直接使用 iPhone 网络打开会改变既有能力。依据：`preview.js:248`、`:254`。
12. **批注偏移和限制是协议。** 必须验证 emoji、中文、组合字符及 Markdown 渲染文本在 JS/Swift 间的定位一致性；不使用 Swift Character 数量代替 JS 字符串长度。依据：`annotation_model.js:148`、`:186`。
13. **队列不仅有排队和取消。** 还包括恢复访问、服务重启核对、结果未知、重试，以及能力允许时的接管和影响确认；未知结果不自动重发。依据：`app.js:3042`。
14. **消息结束与轮次结束不同。** 单消息结束不清除整轮运行态；旧 turn 的完成事件不能关掉新 turn；控制状态用 epoch、版本和请求序号对账，不能凭正文仍更新就判断可写。依据：`chat_model.js:478`、`app.js:2907`。
15. **普通返回与释放资源不同。** 返回保留会话；实际淘汰才释放 SSE、计时器和临时 URL；有草稿、附件、任务或审批的会话受保护。依据：`app.js:3155`、`:3172`、`:3261`。
16. **HTML 预览实际可执行受控脚本。** 旧 scriptless 注释不代表当前实现；本地动态资源仍需可用，同时维持 sandbox 与资源权限。依据：`index.html:59`、`preview.js:613`、`:644`。
17. **diff 和 MCP 的现有范围有限。** diff 仅路径与增删统计，MCP 是平面字段表单；完整 diff 与任意嵌套 schema 引擎属于新增。依据：`app.js:4167`、`:4591`。

## 迁移边界与兼容

当前 App 开放的助手和操作按实时能力与原生入口约束决定；Claude 与主动切换 ttyd 当前被原生适配层拒绝。DSH 外部浏览器入口与 DeepSeek 自绘详情分别检查，不能因展示名相近而混同会话身份或控制协议。

聊天列表、输入、卡片、交互和详情导航由原生承载。HTML 等需浏览器运行的内容允许使用专用 Web 预览，其授权、资源加载、返回、媒体暂停和批注联动仍属于本次范围。文本预览继续执行 5 MiB 上限。来源网络访问继续按 `/host-view` 路由保持原 Mac 的网络环境。

继续复用既有认证与会话协议。当前工作区快照缺少完整正文与详情操作协议，原生化必须提供结构化消息、交互、控制状态和动作接口；不能通过抓取 DOM 维持原生状态，也不能让隐藏网页持续完整渲染第二份聊天。桥接协议须保留现有版本兼容，并校验身份、文档代际及会话身份。

以下属于体验提升或迁移新增能力，不能写成旧版已经支持：原生可复用列表、稳定滚动锚点、流式更新合并、全部进程状态跨重启恢复、附件一键重试、无限 Sub Agent 历史、子会话写入。前三项是本次性能目标；其余依产品范围分别决定，不能用实现便利悄悄扩展。当前也没有明确可达的语音输入/朗读、重新生成、任意编辑已发送消息、fork、会话全文搜索、预览文件编辑保存、完整 diff 审查或还原入口。
