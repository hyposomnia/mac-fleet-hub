# 管理后台用户与设备状态

后台仅提供用户检索、在线状态、设备数量，以及用户详情抽屉中的设备和事件列表。沿用现有视觉与账号权限，不引入前台会话、文件或设备操作。

| 需求 | 可观察验收 | 实现 / 验证 |
| --- | --- | --- |
| ADM-1 | `/admin` 无 Fleet、账号、设备导航；品牌返回后台；浅色、深色、系统使用既有图标、可访问名称和选中态 | admin.html、account.css、account.js；账号页测试及 Chrome |
| ADM-2 | 用户在线表示账号 active，且至少一个未过期 full 网页会话在最近 300 秒内活动；恰好 300 秒仍在线，301 秒离线；未完成认证、已退出、已过期或禁用账号不算在线 | devices.go；admin_presence_test.go |
| ADM-3 | 用户列表显示邮箱、在线状态和现有 device_count；数量不计已撤销设备。用户分页搜索维持服务端总数及 page_size，不按页面长度猜测边界 | devices.go、account.js；Go 与账号页测试 |
| ADM-4 | 点击用户立即打开右侧模态抽屉；显示其设备及在线状态，已撤销设备不展示；没有设备时显示空态。关闭按钮、Escape、遮罩可关闭；错误在抽屉内可重试；关闭或切换用户后迟到响应不可覆盖当前详情 | account.js、account.css；账号页测试及 Chrome |
| ADM-5 | 抽屉显示该用户事件元信息及服务端分页，事件搜索与旧管理 API 保持兼容；不展示消息正文或设备内容；不提供停用、撤销会话、移除设备及前台入口 | account.js；账号页测试与既有 Go 权限测试 |
| ADM-6 | 用户列表在在线状态与设备数之间显示“上次访问时间”，使用浏览器本地时间；无已完成登录访问记录显示 `—`。完整网页会话访问更新账号时间；退出、过期、撤销会话和重启后保留；待验证会话及设备轮询不更新。旧数据从已有 last_login 和 full 会话 last_seen 的最大值回填，迁移可重复启动 | store.go、auth.go、devices.go、account.js；admin_last_access_test.go、账号页测试 |

在线状态在管理员请求时由已有 sessions.last_seen / expires_at / stage 计算；设备在线沿用已有 Headscale 同步结果，active 且 online 的设备显示在线。`online`、`last_access_at` 仅在管理员用户列表及详情投影中返回，普通账号及设备授权模型不变。`GET /api/admin/users` 包含 `page_size`；既有详情、审计分页及管理写接口保持兼容。

账号访问时间保存在 `users.last_access_at`，以 MAX 更新避免并发较早请求覆盖较新时间。启动时事务性新增列并回填旧数据；保留既有 schema 与字段，旧版二进制可忽略新增列回退。访问时间写入错误记录服务端日志，维持既有认证契约。

实施顺序：后端行为失败测试 → 管理员投影与访问记录；前端列表、抽屉、错误与竞态失败测试 → 界面；项目验证入口 → 聚焦提交与推送。完成验证、提交推送后发布到 pm，并核对实际部署与公网服务。服务器发布需二进制与 Web 同步，数据库及密钥先做一致备份，核验 SHA、迁移及健康。回退原二进制和静态资源时保留兼容的新列与访问记录，不涉及 Mac 产物。
