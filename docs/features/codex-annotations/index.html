Codex

参数保持可选，尽量让默认值直接来自当前配置。

默认参数

steps 直接放在 businessParams.steps，省略时使用模型或已选 LoRA 配置的默认值，不再额外增加 advanced 容器。

size 同时接受预设和自定义，例如 1024×1024、1152×768；自定义尺寸按模型对齐要求和显存预算校验。

共享运行时

Desktop 创建 shared runtime，Fleet 复用同一个 listener。配置完成后，需要完全重开 Desktop 并验证浏览器操作。

验收应包含打开网页、点击和截图，同时在两端打开同一个会话，确认只有一个底层 writer。

共享运行时验收

Desktop 创建 shared runtime，Fleet 通过同一个 listener 接入。

迁移与验证

配置完成后，需要完全重开 Desktop 并验证浏览器操作。健康检查只证明 RPC 传输就绪，浏览器后端可能稍后才发布。

在 Desktop 与 Fleet 中打开同一个会话，检查运行时连接与 writer。必须实际打开网页、点击并截图，记录完整的验收证据。

默认参数

参数省略时读取模型或已选 LoRA 配置的默认值。用户显式填写的参数应优先使用，并独立校验。
