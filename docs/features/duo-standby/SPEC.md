# 待机看板设计与开发说明

状态：视觉方向已确认，2026-10-17。原型为本目录 `index.html`；本文区分已绘制的演示行为与开发所需能力。

## 1. 目标与范围

手机横放时，用户能扫视进行中、待回应和未读会话，知道任务持续多久或多久前完成；同时查看时间和今日各模型用量。典型负载为 3–6 个会话。

本文件描述确认的网页设计基准；`index.html` 仍为演示原型，不接入真实数据。后续新增的原生 WidgetKit 与统计接口见 [原生实现说明](WIDGETKIT.md)，其布局、系统刷新边界和验收独立记录，不把 PWA 预览等同于系统待机小组件。

## 2. 布局与视觉

- 设计基准：外屏横向 2034 × 1398，CSS `aspect-ratio:2034/1398`。参考 [Apple 技术规格](https://www.apple.com/iphone-duo/specs/)。外框为 CSS 示意，不是真实硬件模型。
- 画布内边距 6.2%；内容两列，右侧占内容网格约 33%，列间距 4cqw。
- 左侧为活动与未读列表；右侧用细竖线分隔，顶部时钟／日期，底部今日用量。
- 会话无卡片底色，细分隔线；一屏约展示四条，底部淡出提示还有内容。禁止为了容纳六条而不断缩小字号。
- 系统字体栈；标题约 3cqw、辅助信息 1.5cqw。数字钟采用 `ui-rounded / SF Pro Rounded`，回退系统无衬线；时、分按 HH:MM 横排，字号 9.2cqw、字重 650、行高 1，分钟用主题强调色。不下载外部字体。`cqw` 相对画布而不是浏览器窗口。
- 深色默认近黑，正文近白，运行／未读为低饱和绿色，待回应为金色；浅色提供对等层级。开发落地时映射正式主题令牌。
- 原型外部按钮、边框与说明不进入正式待机画面。屏幕内不显示“演示数据 · 非实时用量”；示例数据说明仅保留在画面外和本文中。

## 3. 会话信息与状态

每个会话两行：第一行标题与右对齐状态指示器；第二行使用「电脑图标 + 设备名称」「文件夹图标 + 项目名称」，右侧持续或完成时间。图标沿用现有会话列表 monitor 与 session-project-icon 路径，大小 1em、继承辅助文字颜色。项目名称不是 AI 类型，该行不再显示 Claude/Codex。原型项目名为示例，实际读取会话项目元信息，无项目时不伪造名称。长标题省略，不挤掉指示器；辅助信息空间不足允许换行。

| 状态 | 标题右侧 | 时间 |
| --- | --- | --- |
| 进行中 | 十二辐旋转菊花 | 已持续 N 分钟 |
| 已完成未读 | 实心圆点 | N 分钟前完成 |
| 待回应 | 金色空心圈 | 已持续 N 分钟 |

不显示“进行中／未读／待回应”的可见文字，保留 `aria-label` 与可访问说明。颜色不是唯一状态差别。运行中且有未读时优先显示运行态；待回应优先于运行态。未读来自真实用户阅读状态，不能只按完成时间推断。

持续时间按当前执行轮次开始时间计算，不按会话创建时间；等待回应时继续计算本轮时长。完成时间按最近完成轮次计算。缺时间显示“时间未知”，不能补造时间。展示可用“刚刚”“N 分钟”“N 小时”等精度，避免秒级闪动。

待回应置前，其余以稳定顺序轮播；刷新不得无故打乱位置。读取会话后，已结束且不再未读的项目退出列表；滚动经过不算已读。零条时显示“暂无活动或未读会话”，停用滚动。

## 4. 滚动与可访问性

最新澄清：不是瞬间跳转，而是「停留 → 向上滚动一整行 → 停留」。每 4 秒交替推进会话区／模型区，同一区域每 8 秒触发一次；其中 420ms 为一行的缓入缓出上移动画，其余时间静止阅读，不做持续匀速移动。每次以实际行高计算目标，停在行首。尾部复制一组仅用于视觉循环的内容，滚到复制组时无感复位，末条到首条也保持向上，不反向扫回。复制内容 aria-hidden 且 inert，不重复播报。暂停、焦点、触摸、悬停与页面不可见会暂停动画；减少动态效果时默认不自动轮播，手动恢复后使用无动画切换。

### 直板手机横屏适配

保留左侧会话、右上时钟、右下用量的结构。原型顶部「直板手机／切回 Duo」切换预览，也可用 `?device=phone` 直接打开直板稿。直板参考比例为 19.5:9，不声明对应所有手机型号；正式适配以实际可用视口、安全区及设备尺寸为准。

直板模式减少上下留白，会话行高约 10.4cqw、标题 2.65cqw；右侧占网格 35%，钟面高度 14cqw，用量窗口 9.5cqw，避免窄高空间中互相挤压。数字钟仍为 HH:MM，模拟钟等比缩放，二者可切换。当前交付为带外框的评审预览，正式全屏需移除外部工具栏与说明，适配 safe-area，不把评审页面缩放当作真机可读性验证。

只对实际溢出的区域滚动；内容少时静止。悬停、触摸与键盘聚焦暂停对应区域；触摸结束后预留 6 秒阅读时间。提供暂停机制，尊重 `prefers-reduced-motion`，该偏好下默认不自动滚动且菊花不旋转。

正式实现需处理触摸取消、焦点退出、页面不可见和返回可见；恢复时不要突跳。自动滚动不主动移动焦点、不反复播报每一帧。可点击会话至少 44 × 44 CSS px；进入会话前按实际访问场景验证授权。原型尚未实现点击跳转。

## 5. 时间与用量

- 时钟：已读取浏览器本机时间与日期，24 小时制。占用右上完整区域，两款钟面共用 24cqw 高度与日期位置，不因切换推挤用量区。
- 数字款：HH:MM 横排，大号圆润数字，冒号使用次要色；模拟款：60 个刻度、12 个主刻度、四个方位数字，时针用正文色、分针用强调色，无秒针。时针角度包含分钟偏移。
- 点击整个钟面或使用 Enter/Space 切换数字／模拟；不显示“数字／指针”文字按钮或选项标签。整块是单一 button，保留可见焦点与可访问切换标签，localStorage 记住偏好；存储不可用仍能切换。
- 原型不使用持续指针动画；正式实现建议分钟更新并在恢复可见时校正，控制待机能耗。这里只验证网页钟面，不代表原生系统待机接入。
- 今日：当前用户设置／设备时区的自然日，跨日重置窗口；请求与响应必须携带明确时间范围／时区。
- 合计：所有已覆盖模型的输入 token + 输出 token；不是配额百分比，也不是费用估算。采用与模型明细一致的左右排版，左侧“今日模型用量”（1.95cqw），右侧合计数值（2.2cqw），字重 500、基线对齐；不再将大数字单独放在下一行。原型数值仍为示例，不代表已接入真实用量。
- 模型行：左侧模型显示名，右侧用量，始终横排，数字用 K/M 缩写。按评审批注移除画面内“输入 + 输出 tokens”说明，统计口径仍为输入与输出 token 之和，在文档中保留。
- 模型多时独立滚动，少时静止。长模型名省略，数字不换行、不被挤掉。
- 合计与明细必须来自同一统计窗口，基于原始整数求和后格式化。缓存／推理 token 若已经属于输入或输出，不重复累加。
- 未覆盖的提供商、数据缺失、更新失败不显示为 0；标明“暂无数据”或“部分模型”，并提示最近更新时间，避免部分统计冒充所有模型总量。

## 6. 数据接入要求（逻辑需求，不是已存在接口声明）

| 数据 | 所需字段／语义 |
| --- | --- |
| 会话标识 | 稳定 session ID、设备 ID、归属当前用户 |
| 展示元信息 | 标题、设备显示名、AI 类型；模型显示名另行归一化 |
| 状态 | 执行状态、待回应状态、当前用户未读状态 |
| 时间 | 当前轮次 startedAt、最近轮次 completedAt、数据更新时间 |
| 用量 | 模型 ID、显示名、输入／输出 token、统计窗口、时区、覆盖完整性与更新时间 |

后续开发先复用现有会话／运行／阅读状态能力并核对语义，再确定用量聚合方案；本设计没有证明所有模型用量接口已存在。跨设备数据需要去重，shared 会话不能因多个客户端观察而双计。不得从示例数组推导真实字段契约。

只展示当前已认证用户可见数据，不泄露聊天正文、文件路径或审批内容。会话标题仍可能敏感；原生锁屏场景的隐藏策略需要单独确认。退出、切换用户、撤权时清除私有列表与连接，不能因待机展示绕过原有 owner 检查。

## 7. 开发验收

- 保持固定画布比例；时钟、长标题、长模型名、用量数字不溢出。
- 3／4／6 个会话和 0 个会话均验证；一、二、多模型均验证。
- 状态文字不可见，标题右侧指示器与真实状态一致，辅助技术可辨识。
- 会话与模型错峰滚动；暂停、触摸、键盘、减少动态效果均有效。
- 验证今日边界、时间未知、断网、部分用量、阅读后消失和执行状态转换。
- 深／浅主题与目标横屏尺寸实测，真机检查阅读距离、触摸目标、烧屏风险与能耗；不将桌面截图当作真机验证。
- 原生系统待机接入、后台刷新及锁屏隐私另行报告，不包含在本次视觉确认的完成声明中。
