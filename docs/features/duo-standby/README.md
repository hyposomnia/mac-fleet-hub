## 本地预览

从仓库根目录执行：

```sh
python3 -m http.server 8789 --bind 127.0.0.1 --directory docs/features/duo-standby
```

打开 `http://127.0.0.1:8789/`。顶部暂停与主题按钮、机身边框、底部说明均为评审工具，不属于最终产品画面。页面不依赖 CDN、图片生成或私有目录，可独立预览。

## 确认的方向

- 按外屏横向 `2034:1398` 固定画布比例绘制，不使用生成图决定几何。
- 常态有 3–6 个活动会话，采用滚动会话窗口，不使用六宫格，也不让大时钟占据主体。滚动为停留后 420ms 上移一整行，不是持续移动，也不是瞬间跳转。
- 顶部可切换 Duo／直板手机横屏；直板参考比例 19.5:9，使用 `?device=phone` 直接预览，保留相同左右结构。
- 标题右端显示运行菊花、未读点或待回应空心圈；去掉可见状态文字。
- 设备与项目名称前分别使用电脑／文件夹图标，持续／完成时间放在同一辅助信息行。
- 右上完整钟面可点击切换数字／模拟并记住偏好；数字款按 HH:MM 横排，模拟款为刻度与双指针。右下今日 token 合计与模型明细均为左右横排，溢出时滚动。

## 验证记录

确认稿使用 Playwright 在 1173px、430px 宽度下检查明／暗主题：画布实测比例约 `1.45497`、页面无横向溢出、时钟未溢出、6 个状态指示器均渲染。前一轮已验证会话容器可滚动且自动滚动位置发生变化。

新版时钟已检查 1173px／430px × 明暗 × 数字／模拟共八种组合，无页面横向溢出，钟面未与用量区重叠；键盘 Enter 切换与刷新后偏好恢复通过。

这些结果仅证明浏览器设计稿；窄屏缩放不是 iPhone 真机阅读距离或系统待机集成验收。时钟使用本机时间；模型、用量、会话及会话时间仍为静态示例。
