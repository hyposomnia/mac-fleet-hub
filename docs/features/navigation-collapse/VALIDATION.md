# 侧栏收起交互

> 当前行为已更新为仅展开 / 收起两态，见 [v172 两态规范与验证](two-state/README.md)。下文为 v161 历史记录，其中浮层与图钉行为已移除。

2026-10-02，源码位于 `codex/multi-user-server` 工作区，仅本地实现与验证，未发布生产。

## 行为

- 设备栏头部提供收起/展开按钮。收起宽度 72px，会话/文件及设备 SVG 图标竖向排列，隐藏名称及数量，保留名称提示和设置入口。
- 会话列表头部提供图钉按钮：pinned 显示实心图钉，unpinned 显示带斜线的图钉，状态同步到 `aria-pressed`。取消固定后主窗口获得原列表空间，左上方显示悬浮列表入口。
- 新建会话从助手标题行移至下一行搜索框右侧，桌面/浮层与移动布局保持原有新建行为。
- 点击入口以浮层呼出原会话列表，原有筛选和搜索结构保留；选择会话、点击外部或 Escape 收回。浮层内可固定回侧栏。
- 两个收起状态分别保存到当前浏览器，刷新恢复收起偏好，不恢复临时浮层。禁用存储时仍能在当前页面使用。
- 文件模式隐藏列表呼出入口；860px 及以下沿用既有移动导航，桌面偏好不把移动列表锁定为不可操作。
