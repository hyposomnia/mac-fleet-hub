# Fleet Hub 品牌与界面规范

设计方向：墨黑 / 暖瓷白 / 香槟金。用暖调中性色、稳定的几何标记与小面积金色建立质感；保留当前信息架构、组件与布局。

## 1. 标识

标记由一片上移的窗口横梁和切角 F 主干构成：上层表达窗口叠放，F 对应 Fleet，统一入口由共享主干表达。96 × 96 的坐标系统，横梁厚 12、主干厚 14，45° 端部切角；主干加厚补偿小尺寸视觉重量。

- 主标识：`assets/logo-mark.svg`，香槟金；单色深/浅版本分别为 `logo-mark-dark.svg`、`logo-mark-light.svg`。
- 可随界面继承颜色：`assets/logo-mono.svg`，使用 currentColor。外部 img 不继承父级颜色；需要动态换色时内联 SVG 或 CSS mask。
- 最小显示尺寸 24px；小于 24px 使用 `favicon.svg` 的带底版本。标记外部额外留白至少为主干厚度，约可见标记高度的 1/5。
- 不拉伸、不加描边、光晕、渐变或拆分两片图形。单色版保持同一几何。
- Wordmark 使用项目既有系统字体、500–600 字重、`fleet hub` 小写。组合 `logo-lockup.svg` 是可编辑系统文本示意，具体字形随平台字体变化；界面组合优先直接使用 SVG 标记与 HTML 文本，不把整个组合缩为图片。

## 2. App icon

`app-icon.svg` 是完整 512 × 512 墨黑方形画布，核心标记约 208 × 228px，光学居中。透明 Logo 与有底 App icon 分别使用，避免混用。

| 文件 | 用途 |
|---|---|
| `icon-1024.png` | 高分辨率通用 App icon 母版 |
| `icon-512.png` / `icon-192.png` | PWA 安装 |
| `icon-180.png` | Apple touch icon |
| `icon-maskable-512.png` | PWA maskable，完整不透明背景 |
| `favicon.svg` | favicon，单独带圆角底 |
| `app-icon-light.svg` / `icon-light-512.png` | 浅色应用场景参考 |
| `app-icon-jade.svg` / `app-icon-platinum.svg` | 备选强调色参考 |

安装 PNG 画布不预切圆角，由系统裁切。规范页的圆角仅用于展示系统外观。标记全部落在中心半径 0.4 × 边长的 maskable 安全圆内，黑色背景铺满画布。安装图标固定默认墨黑金色，页面浅色主题不需要替换主屏幕图标。

`manifest.proposed.json` 是可在设计目录测试的参考片段；集成时只迁移颜色与 icon 定义，保留生产 manifest 的 id、scope、start_url、名称和 shortcuts。

### 强调与状态

- 推荐香槟金：深色 #D2B78D；浅色 #82643A。浅色必须改成深铜金，不能直接使用浅香槟金承载文字。
- 深玉绿：深色 #A7C4B7；浅色 #426B5B。保留同一中性底色，气质偏静谧。
- 冷铂灰：深色 #C7CCD0；浅色 #59656E。保留同一中性底色，气质偏精密。
- 在线/成功：#91B69F / #426A53；等待/确认：#D8BA79 / #7D5C21；错误/危险：#E5A19B / #A7433B。
- 强调色约占可见界面的 5–8% 为设计目标，不扩展成大面积金色背景。状态色不能被品牌色替换；必须同时有文本、形状或位置反馈。
- 正常信息文字对比度至少 4.5:1；关键图标、控件边界和焦点至少 3:1。分隔线不是操作边界，可低于控件对比度。弱文字仍应可读；禁用控件另保留不可操作的语义。
- `.modeseg`、`.btn.primary`、`.iconbtn.primary-action`、`.account-button.primary` 的普通/hover 文字使用 `--accent-contrast`。这也是本提案新增的颜色语义，避免金色底配白字。
- `--brand-grad` 为兼容原选择器保留，但值改为纯色。正式集成可以统一品牌填充变量，不新增装饰渐变。

### 聊天与代码

保留 `--chat-*` 变量体系、消息流、工具行和输入器几何；色温映射至外壳，不把所有聊天内容染成金色。正文暖白、元信息灰绿、链接铜金；代码语法继续使用区分关键字、字符串、数字、错误的多色语义。实际变量值在 tokens.css。

## 4. 几何、排版与交互

- 桌面主机栏 260px、会话栏 330px、工作区弹性；文件模式继续两栏。860px 及现有更细断点保留，移动端继续列表→全屏会话与返回。
- `--font`、`--mono` 与字号阶沿用生产 CSS：11 / 12 / 13 / 15 / 16 / 17 / 28px。规范页展示的大字只用于规范文档，不进入产品界面。
- 间距沿用 4pt 系列；圆角沿用 8 / 12 / 16 / 22px。现有输入器 24px 与局部圆角保持原值，避免全局统一造成几何变化。
- hover 用表面升阶，选中用强调色低透明背景与细边线，focus 用可见的 2px 强调轮廓/原有 ring。不要以光晕承担焦点识别。
- 过渡沿用 140 / 220 / 400ms 和原有缓动；尊重减少动效偏好。保留安全区与 VisualViewport 行为。
- 普通 dashboard 采用当前实现的图标；Codex 工具行保留项目 Lucide 图标与许可。品牌标记不作为操作图标重复使用。
- 移动端本次涉及的操作命中区至少 44px，可通过命中区 padding 扩展，保持图形视觉尺寸。预览对会话行、输入器按钮、范围按钮增加命中尺寸；这部分是无障碍验收补充，需开发分别核对，不整页放大。

## 5. 实现映射

| 设计交付 | 生产落点 | 集成事项 |
|---|---|---|
| 颜色令牌 | `server/dashboard/style.css` | 合并 :root、light 与 chat/syntax 颜色；保留几何 |
| Logo 标记 | `index.html` 的 `.brand .logo`、移动品牌位及账户品牌 | 替换图形，保留文字、hook 和容器尺寸 |
| 安装图标 | `server/dashboard/icons/` | 对应替换 SVG / 180 / 192 / 512 / maskable 文件 |
| 系统外观 | `index.html` 首屏主题脚本、`app.js` THEME_COLORS | 深色系统外观 #111310，浅色 #F4F1E9；主题偏好与事件不变 |
| 终端背景 | `app.js` XTERM_THEME | 同步背景、文字、cursor 与选择区域；保留 ANSI 语义差异 |
| 安装清单 | `manifest.webmanifest` | 更新图标与颜色，保留所有路由及应用身份 |
| 缓存 | `sw.js` | 按项目流程更新缓存版本和资源列表；不缓存 API / 终端 / 用户文件 |
| 登录与账户 | `account.css`、相关 HTML | 复用相同颜色变量，保持认证流程 |

`base.css` / `account-base.css` 是当前生产样式的设计快照，不部署、不用于覆盖现有样式。`source-snapshot.json` 记录来源 SHA 和关键布局；其他工作推进后，集成应重新比对。

预览页面从当前 index.html 提取 app 标记，完全不加载生产 app.js、认证脚本或 Service Worker。示例设备、会话、工具结果、文件为模拟内容；发送消息只更新本地 DOM，所有服务操作提示未连接。审阅工具条只属于原型。

## 6. 验收

- Logo 单色/反白、24px 和大尺寸可识别；所有 icon 画布尺寸正确，安装图标完全不透明，maskable 核心在安全圆内。
- 明/暗 × 桌面/移动；聊天、会话列表、文件列表与登录页都有检查证据，无横向溢出。
- 三种强调色都验证普通/hover 的文字对比度、选中与 focus；主方案弱文字在背景与表面升阶上达到 4.5:1。
- 主要操作和输入有可见 focus、可访问名称；桌面键盘与移动命中区可用。移动键盘/standalone 实机验证属于集成后的验收，不由桌面浏览器截图代替。
- 集成后按 AGENTS.md 运行项目验证入口，检查缓存更新和离线外壳；本设计交付不改变生产前端。
