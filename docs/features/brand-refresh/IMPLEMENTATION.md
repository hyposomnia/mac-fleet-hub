# Titanium Web 落地

依据已确认的 `variants/titanium/SPEC.md`，保留三栏几何、860px 断点与现有业务流程。修改范围仅服务器静态页面和共享主题资源的公开加载路径；独立本地验证，不部署生产或改动现有 Mac 客户端。

1. 共享 `theme.js`：首屏同步加载，默认浅色，保留显式深色；system 显式持久化，系统变更仅在 system 下生效；同步浏览器 chrome、控件状态与跨标签页变化。新增状态行为测试和未登录静态资源加载测试。
2. 就地整合 `style.css` / `account.css`：Titanium 语义令牌、8/12/16/20px 圆角、无装饰边框，保留状态旋转环和可见焦点反馈。
3. 全页面品牌标识、原生安装图标与 manifest，统一外壳版本及缓存清单。
4. 菜单增加键盘打开、上下键导航、Escape 关闭及焦点恢复；维持现有菜单动作。
5. 独立 localhost 服务验证 HTTP 边界，浏览器检查登录/账号/桌面/移动/深浅主题和实际计算样式；运行完整 scripts/verify.sh，保存真实证据。
