# 05 · 夜航玫瑰

## 设计语言

弧形开口 · 宽字距 · 夜色对照。

**标识逻辑**：一道开放的环抱与水平入口，表达进入工作空间的路径。

**字标**：纤细大写字标与宽字距；暗色空间中保持清晰层级。

**界面材质**：深葡萄色、灰玫瑰与冷白；低调、戏剧性、安静。

品牌字标和原型中小范围的表面处理可变化；正文系统字体、三栏 260 / 330px、组件位置、间距与 860px 断点沿用原框架。输入器维持整体容器，操作与 API 契约不变。

## 标识与图标

原始标记 96×96，最小使用 24px；安装图标为 512×512 不透明方形，由系统裁切。提供单色、反白、浅色 icon 与 180 / 192 / 512 / 1024px PNG，maskable 背景铺满且核心在中心安全圆内。标记不拉伸、拆分、添加光晕或装饰描边。

SVG 内的连续曲线/几何结构是标识本身，不随控件圆角修改。字标可用 HTML 和系统字体呈现；产品正文不采用展示页的排版尺寸。
