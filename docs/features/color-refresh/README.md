# Fleet Hub 中性绿松蓝配色

这组高保真稿用于确定并维护生产 Web 的中性绿松蓝配色，不改变信息架构与业务行为。它保留单一画布、无装饰边框、系统字体、圆角尺度和三栏结构。

## 蓝色调色盘

- **01 澄蓝**：浅色 `#116B98`，深色 `#56BDEB`；最偏蓝。
- **02 海湾蓝**：浅色 `#00728F`，深色 `#43C8E2`；轻微偏绿。
- **03 青海蓝**：浅色 `#007989`，深色 `#36CFD6`；蓝绿比例居中。
- **04 孔雀蓝**：浅色 `#007E7E`，深色 `#43D3C8`；明显偏绿。
- **05 绿松蓝（已选）**：浅色增绿为 `#087F65`，深色保持 `#5BD7B7`。

最终选择 05 绿松蓝，并仅把浅色主题进一步向绿色移动。五档共享完全相同的纯白 / 纯黑画布与酸性荧光黄辅助色。分栏、气泡、输入器和选中底只使用极轻的中性明度差。主题色负责选中、链接、主要操作与状态主体；荧光黄只在主题色旁形成细小状态环或 focus 外环。

每个方向都提供浅色、深色和移动端响应式预览。示例内容来自现有 Fleet Hub 会话界面，不连接服务。05 绿松蓝已同步到 `server/dashboard/` 的生产样式、浏览器主题色、终端主题和品牌图标资产；其余方向仅保留为选型记录。

## 本地预览

从仓库根目录运行：

```bash
python3 -m http.server 8877 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8877/docs/features/color-refresh/`。

可直接使用查询参数打开指定状态，例如：

```text
?palette=clear&theme=light
?palette=ocean&theme=dark
?palette=turquoise&theme=light
```

## 文件

- `index.html`：可交互选择稿。
- `palette.css`：三套明暗配色与预览组件样式。
- `preview.js`：仅用于切换配色、主题和同步 URL。
- `SPEC.md`：确认方向后的生产映射与验收范围。
- `screenshots/`：浏览器实测截图。
- `revisions/`：保留已否决的有色画布版和“双操作色”版，避免与当前方向混淆。
