# Fleet Hub 色彩优化开发规范

## 状态与范围

**状态：已确认并落地到生产 Web（2026-10-08）。** 本文与 `docs/titanium-design.md` 共同作为后续页面和品牌资产的颜色规范；若两者冲突，以本页的色值与使用边界为准。

本轮只替换色彩令牌及由这些令牌派生的主题色，不改布局、间距、圆角、字体、DOM 结构、业务状态或事件契约。浅色尽量贴近纯白，深色尽量贴近纯黑。

生产落点：

- `server/dashboard/titanium.css`：外壳、聊天和设备颜色的设计令牌。
- `server/dashboard/style.css`：文件顶部的重复主题令牌需同步，避免加载顺序出现闪烁或回退色。
- `server/dashboard/index.html`：`meta[name="theme-color"]` 的浅色默认值。
- `server/dashboard/theme.js`：若内含固定的浏览器主题色映射，随最终方向同步。
- `server/dashboard/account.css`：确认登录、账户和管理员页面只消费共享令牌；固定颜色需要映射回同名令牌。

## 用户配置模型

“设置 → 外观”分别为浅色和深色暴露四个种子颜色：

| 配置 | 浅色默认 | 深色默认 | 作用 |
|---|---:|---:|---|
| `canvas` | `#FAFAFA` | `#000000` | 页面画布及浏览器主题色 |
| `accent` | `#087F65` | `#5BD7B7` | 主要操作、链接与选中状态 |
| `highlight` | `#D9F23A` | `#EDFF52` | 只强化主题色的反差辅助色 |
| `text` | `#18211F` | `#F4F7F6` | 正文基准字色 |

其余表面、hover、次级文字与主题色层级由 `theme.js` 在 OKLCH 色彩空间自动混合生成。设置保存在当前浏览器的 `fleet-theme-palette-v1`，不改变账号数据或设备状态。非法或缺失颜色逐项回退为上表默认值。

会话列表与会话详情是固定例外，不从 `canvas` 派生：浅色继续使用纯白，深色继续使用列表纯黑、详情近黑。Logo、favicon 和安装图标使用规范默认色，不跟随个人浏览器配色。

## 令牌映射

三个方向都维持现有变量契约：

| 角色 | 现有令牌 | 约束 |
|---|---|---|
| 页面底色 | `--bg` | 浅色为白，深色为近黑；不带主题色色相 |
| 区域表面 | `--surface` / `--surface-1` | 保持单一画布感；相邻栏只用中性明度差 |
| 控件表面 | `--surface-2` | 与底色有可感知但克制的中性色差 |
| 悬停 | `--surface-hover` | 比控件表面再深或再亮一级 |
| 正文层级 | `--text` / `--text-1` / `--text-2` / `--text-3` | 不用同明度灰复制四份；保持层级和 WCAG 对比 |
| 主题色 | `--accent` / `--accent-1` / `--accent-text` | 只用于选中、链接与焦点 |
| 反差辅助 | 新增 `--highlight` | 色相必须与主题色形成反差；只在主题色状态点外环、focus 外环等极小范围强化主题色，不作为按钮底色 |
| 软强调 | `--accent-soft` | 从主题色派生，仅用于极浅选中底、文字选择或焦点内环，不形成大面积有色表面 |
| 状态 | `--online` / `--wait` / `--danger` / `--offline` | 保留语义，不借状态色做装饰 |

聊天相关的 `--chat-*` 继续映射到外壳令牌，不另建一套颜色。设备自定义色保持现有八色，只在最终方向确定后校准明暗主题下的对比度。

## 主题蓝绿候选

辅助色固定为浅色 `#D9F23A` / 深色 `#EDFF52`，仅比较主题蓝：

| 编号 | 名称 | 浅色主题 | 深色主题 | 色相位置 |
|---|---|---|---|---|
| 01 | 澄蓝 | `#116B98` | `#56BDEB` | 最偏蓝 |
| 02 | 海湾蓝 | `#00728F` | `#43C8E2` | 轻微偏绿 |
| 03 | 青海蓝 | `#007989` | `#36CFD6` | 蓝绿居中 |
| 04 | 孔雀蓝 | `#007E7E` | `#43D3C8` | 明显偏绿 |
| 05 | 绿松蓝（已选） | `#087F65` | `#5BD7B7` | 浅色进一步增绿 |

最终选定 05 绿松蓝：浅色主题 `#087F65`，深色主题 `#5BD7B7`。

会话列表与会话详情是画布规则的明确例外：浅色主题固定使用 `#FFFFFF`，不得被页面的 `#FAFAFA` 画布覆盖；深色主题继续使用列表 `#000000`、详情 `#050606`。

## 品牌与图标

- 三折面 Logo 几何保持不变，界面内使用 `currentColor` 跟随当前主题色。
- favicon 固定为 `#087F65`；PWA 安装图标使用 `#FAFAFA` 画布与 `#087F65` 标记。
- 酸性黄不进入 Logo、favicon 或安装图标主体。
- 常规界面 SVG 继续使用 `currentColor`；只有选中、主要操作和活动状态才显示主题色。
- 文件类型、危险、等待等语义图标保留自身颜色，不强制绿松蓝化。

## 验收

- 浅色、深色 × 桌面三栏、移动单栏四态截图。
- 正文、次级文字、选中态、按钮、输入焦点满足可读性；正文目标对比度至少 4.5:1。
- `prefers-reduced-motion`、键盘 focus、触控目标不因配色改动退化。
- 终端 xterm、文件预览、账户/登录/管理员页面与主 dashboard 主题一致。
- 不新增外部字体、框架、构建步骤或在线资源。
