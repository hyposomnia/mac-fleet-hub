# 登录页鼠标跟随 · 五方案评审

这是最初的五方案调研档案。用户先选择 05 并取消表单遮罩，随后要求改成更安静的星光：光点从屏幕四周随机飞向鼠标。最终实现和当前验证见 [星光发布记录](../../releases/auth-starlight-2026-10-08/README.md)。本目录截图保留首次评审状态，不代表最终上线效果；当前原型默认选择 05，已移除表单遮罩与表单悬停/焦点抑制。

直接打开 [index.html](index.html)，或从本目录启动本地预览：

```bash
python3 -m http.server 8788 --bind 127.0.0.1
```

入口为 `http://127.0.0.1:8788/`。可用 `?demo=1` 到 `?demo=5` 指定方案，附加 `&theme=dark` 预览深色。

| 编号 | 方案 | 体验差异 |
| --- | --- | --- |
| 01 | 柔光追随 | 宽而柔的钢蓝光，轻缓地跟随；装饰最安静 |
| 02 | 磁性点阵 | 鼠标拨开邻近的点，点阵亮起并归位；优先推荐 |
| 03 | 精密光环 | 小型双层光环随速度轻微形变；反馈最直接 |
| 04 | 金属掠光 | 银蓝细线产生局部弯曲与光泽；更强调材质 |
| 05 | 弹性丝带 | 多股细丝延迟跟随、自然转向；停下后消散 |

在上方空白区域移动鼠标；也可以开启“自动演示”，切换五个方案比较。效果开关用于比较纯静态页面。方案标签支持左右箭头和 Home / End。触屏默认没有跟随，仍可主动开启自动演示；系统减少动态效果时自动演示也会禁用。

原型使用只读示例字段，登录、注册和恢复按钮只展示预览反馈。没有账号连接、生产请求、持久化或生产资源替换。
