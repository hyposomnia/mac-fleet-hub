# 设备文字图标：1–3 个字符

支持 1–3 个 ASCII 英文字母或数字，可混合输入，如 MBP、009、A1B。字母自动转为大写，数字保留前导零。输入校验、即时预览、保存和恢复使用同一规则。

三字符沿用 22px 图标区域，采用 11px 等宽字体，最宽 WWW 实测 18.8828125px；一、二字符保留原样式。
