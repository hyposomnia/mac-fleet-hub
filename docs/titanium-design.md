# 中性绿松蓝设计规范

> 文件名沿用 `titanium-design.md` 以保持现有引用稳定；当前生效方向已由“精密钛银 / 钢蓝”更新为中性绿松蓝。

设计来源：`docs/features/color-refresh/` 中经确认的 05 绿松蓝方案及现有三折面 SVG 母版。

## 共用基础

`server/dashboard/titanium.json` 是 Web / iOS 共用的色彩、圆角、字号与导航尺寸来源。Web 使用生成的 `titanium.css`；iOS 在构建时将同一 JSON 打包为只读资源，由 `TitaniumStyle` 转为系统动态颜色和尺寸。不要分别修改 CSS 与 Swift 的颜色、字号或栏宽。

```sh
node scripts/titanium-design.mjs --write
node scripts/titanium-design.mjs --check
bash scripts/verify.sh
```

## 色彩原则

画布由白 / 黑主导，主题色只表达操作和状态，不进入大面积背景。辅助色只强化主题色，不单独承担主要操作。

| 语义 | 浅色 | 深色 | 使用范围 |
|---|---:|---:|---|
| 页面画布 | `#FAFAFA` | `#000000` | 页面底色与浏览器主题色 |
| 会话内容底色 | `#FFFFFF` | 列表 `#000000` / 详情 `#050606` | 会话列表与会话详情的固定内容表面 |
| 主表面 | `#FFFFFF` | `#050606` / `#090A0A` | 导航、内容、浮层 |
| 次级表面 | `#F1F4F2` | `#171B19` | 输入、代码块、弱选中 |
| 主题色 | `#087F65` | `#5BD7B7` | 主按钮、链接、选中、状态主体、Logo |
| 主题色强调 | `#06644F` | `#88E4CB` | hover 与深浅层级 |
| 反差辅助色 | `#D9F23A` | `#EDFF52` | 运行状态外环、focus 外环等极小范围 |

- 不把绿松蓝铺进页面、栏位或大卡片背景；弱选中使用 `--accent-soft`。
- 浅色主题的会话列表与会话详情始终使用纯白底，不跟随近白页面画布；深色主题保持既有黑色层级。
- 不把酸性黄用于发送按钮、整块选中底、Logo 主体或独立大面积元素。
- 主发送按钮、品牌标记和活动链接使用主题色；普通工具图标保持 `currentColor`，仅在选中或主要操作时继承主题色。
- danger / wait / online 和文件类型图标保留各自语义色，避免为了统一而损失辨识度。
- 容器无常驻描边；层次主要来自中性表面明度差、留白与克制阴影。

### 可配置配色

Web 的“设置 → 外观”允许分别为浅色和深色配置四个种子色：页面画布 `canvas`、主题色 `accent`、反差辅助色 `highlight` 与正文 `text`。上表中的颜色是默认值；用户配色保存在当前浏览器。

`theme.js` 根据当前明暗模式即时派生 `--surface`、`--surface-1`、`--surface-2`、`--surface-hover`、`--text-1`、`--text-2`、`--text-3`、`--accent-1`、`--accent-text` 与 `--accent-contrast`。派生只允许在种子色与画布 / 字色之间做 OKLCH 混色，不增添第三套装饰色。`--accent-soft`、focus ring 等继续引用派生后的主题色与反差色。

会话列表和会话详情不参与画布派生：浅色固定 `#FFFFFF`，深色固定列表 `#000000`、详情 `#050606`。品牌安装图标也使用设计规范默认色，不随单个浏览器的个人配色改变。

圆角统一为小控件 8px、标准控件 12px、内容卡片 16px、输入器 / 弹层 20px。手机主要操作至少 44px；系统控件、状态点和头像不强行改形状。

## 主题与兼容

新用户默认浅色；已保存的浅色 / 深色选择继续有效。跟随系统作为显式偏好保存，避免与默认浅色混淆。Web 与 ttyd 使用当前设计令牌；Web 的自定义种子配色保存在浏览器本地并跨页面生效。App 通过现有版本 1 快照的可选主题字段同步原生栏，不新建 WebView、不重启会话。旧快照缺少主题字段时采用浅色。

网页与 App 均以实际可用宽度 860 为单栏 / 三栏断点；861–1180 的栏宽为 220 / 310，更宽时为 260 / 330，收起设备栏为 72。手机采用 H5 的文字标题切换、设备选择面板和 44px 操作；宽屏采用 Web 的栏内标题、36px 操作和图钉，无全局重复顶部导航。App 的 WebView 内部可能窄于 860，因此用独立的 native-layout 标记决定会话头部，不拿内嵌窗口宽度误判外部导航。无业务 API、设备授权或生产网络调整。

## 标识

标识继续复用三折面空心六角 SVG：`server/dashboard/icons/logo.svg`，不重绘几何。界面内 Logo 使用 `currentColor` 跟随主题色；favicon 固定使用浅色主题色 `#087F65`。Web 安装图标从 `icons/icon.svg` 同一母版导出，画布 `#FAFAFA`、标记 `#087F65`；PNG 保持不透明方形，不预裁切四角。酸性黄不进入品牌主标。

PWA 缓存版本与资源引用同步升级，包含共用主题与标识。网页端不依赖 iOS 构建工具即可继续迭代。

本地模拟后端与模拟器测试不代替真实网关登录、真实终端 WebSocket 或 Duo 硬件验证。
