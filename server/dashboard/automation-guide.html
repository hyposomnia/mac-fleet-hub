从外部系统向内网 AI 会话发送消息

使用访问密钥发送消息，可指定设备、AI 客户端、项目和会话，或使用指向已有会话的别名。提交接口立即返回 message_id，随后通过查询接口或 HTTPS 回调获取最终回复。

1. 创建访问密钥

打开 自动化 → 访问密钥，点击“新建密钥”。可依次绑定设备、AI 客户端、项目绝对路径和已有会话 ID；后续层级留空即允许该层级下所有目标。绑定会话的密钥只能继续该会话，不能新建会话。只能从设备到会话依次指定，不能跳过前一级。可通过“编辑”调整现有密钥的范围。

密钥可随时回来查看。请求时放入 Authorization: Bearer …，不要写在 URL 中。

2. 创建会话别名

在同一管理页点击“新建别名”，为一个已有会话选择设备、客户端、项目绝对路径和会话 ID，再填写别名。别名一对一定位这个会话，创建时会验证会话确实属于所选目标；可随时编辑或删除。外部系统只需知道别名，不必取得设备或项目的内部标识。

别名与访问密钥独立管理。调用时仍会验证该密钥是否有权访问别名所指向的会话。

3. 提交消息

使用别名（推荐对外集成）：

curl -sS https://fleet.hyposomnia.top:20443/api/v1/messages \
  -H 'Authorization: Bearer mfh_live_替换为你的密钥' \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: your-request-001' \
  -d '{"alias":"daily-review","message":"检查项目状态，只回复简要结论"}'

也可以直接指定目标：

curl -sS https://fleet.hyposomnia.top:20443/api/v1/messages \
  -H 'Authorization: Bearer mfh_live_替换为你的密钥' \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: your-request-001' \
  -d '{
    "device": "mac-dev",
    "ai_client": "codex",
    "project": "mac-fleet-hub",
    "message": "检查项目状态，只回复简要结论"
  }'

成功返回 HTTP 202：

{"message_id":"msg_xxx"}

请求字段

字段必填说明
alias二选一已创建的会话别名，与 device / ai_client / project / session 不可同时出现。
device直接指定时必填设备显示名称，兼容 m1 等设备 ID。
ai_client直接指定时必填codex 或 deepseek。
project直接指定时必填项目名称，重名时改用完整路径。
session否会话名称或 ID；省略时新建会话。
message是发送给 AI 的用户消息。
callback_url否接收终态结果的公网 HTTPS 地址。

设备、项目和会话匹配均不区分大小写。名称重名时接口会返回候选路径或 ID，按提示重新提交即可。

若密钥已绑定范围，请在请求中提供该范围内的目标或指向该范围的别名；直接指定绑定会话时必须传入对应的 session。不匹配的目标返回 403 access_key_scope_mismatch。

4. 查询结果

curl -sS \
  -H 'Authorization: Bearer mfh_live_替换为你的密钥' \
  https://fleet.hyposomnia.top:20443/api/v1/messages/msg_xxx
queued 队列中running 执行中 completed 已完成failed 失败

completed 时读取 ai_message.content。别名模式下，查询结果和回调的目标字段只显示 alias，不返回设备、客户端、项目或会话 ID。直接指定且新建会话时请保存响应中的 session_id；后续请求传入该 ID 即可继续同一会话。

5. 回调与安全重试

提供 callback_url 后，网关会在完成或失败时 POST JSON。完成回调至少包含 message_id、status 和 ai_message。

Idempotency-Key 不是访问密钥。每条新消息使用不同值；网络失败重试同一条消息时复用原值，可避免 AI 重复执行。

常见响应

  • 401 invalid_access_key：密钥缺失、错误或已删除。
  • 403 access_key_scope_mismatch：目标超出密钥绑定范围。
  • 404 target_alias_not_found：别名不存在或已删除。
  • 400 invalid_target：同时提交了别名与直接目标。
  • 409 ambiguous_project：项目重名，使用返回的完整路径。
  • 409 ambiguous_session：会话重名，使用返回的会话 ID。
  • 503 device_unavailable：目标设备当前不可达。
