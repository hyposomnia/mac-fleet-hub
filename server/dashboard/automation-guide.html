从外部系统向内网 AI 会话发送消息

用密钥名称定位其绑定的会话，或直接指定目标。提交后返回 message_id，可查询结果或接收回调。

1. 创建访问密钥

打开 自动化 → 访问密钥，点击“新建密钥”。名称就是别名。若要用别名调用，须把密钥绑定到设备、客户端、项目绝对路径和已有会话 ID。绑定范围只能按这个顺序逐级指定；后续层级留空表示全部，留空时只能显式指定请求目标。编辑名称会立即改变别名。每个密钥可设置 RPM，默认 10。

请求头使用 Authorization: Bearer …。

2. 提交消息

使用密钥名称：

curl -sS https://fleet.hyposomnia.top:20443/api/v1/messages \
  -H 'Authorization: Bearer mfh_live_替换为你的密钥' \
  -H 'Content-Type: application/json' \
  -d '{"alias":"每日同步","message":"检查项目状态"}'

或直接指定目标：

curl -sS https://fleet.hyposomnia.top:20443/api/v1/messages \
  -H 'Authorization: Bearer mfh_live_替换为你的密钥' \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: your-request-001' \
  -d '{
    "device": "mac-dev",
    "ai_client": "codex",
    "project": "mac-fleet-hub",
    "message": "检查项目状态，只回复简要结论"
  }'

成功返回 HTTP 202：

{"message_id":"msg_xxx"}

请求字段

字段必填说明
alias二选一此 Bearer 密钥的名称；需要密钥绑定到具体会话，不能与目标字段同时传入。
device显式调用必填设备显示名称，兼容 m1 等设备 ID。
ai_client显式调用必填codex 或 deepseek。
project显式调用必填项目名称，重名时改用完整路径。
session否会话名称或 ID；省略时新建会话。
message是发送给 AI 的用户消息。
callback_url否接收终态结果的公网 HTTPS 地址。

设备、项目和会话匹配均不区分大小写。名称重名时接口会返回候选路径或 ID，按提示重新提交即可。

显式目标须在密钥绑定范围内；绑定会话时须传入对应的 session。不匹配的目标返回 403 access_key_scope_mismatch。

3. 查询结果

curl -sS \
  -H 'Authorization: Bearer mfh_live_替换为你的密钥' \
  https://fleet.hyposomnia.top:20443/api/v1/messages/msg_xxx
queued 队列中running 执行中 completed 已完成failed 失败

completed 时读取 ai_message.content。别名调用的响应及回调仅返回 alias 作为目标标识，不返回设备、客户端、项目或会话 ID。显式调用新建会话后，请保存返回的 session_id。

4. 回调与安全重试

提供 callback_url 后，网关会在完成或失败时 POST JSON。完成回调至少包含 message_id、status 和 ai_message。

Idempotency-Key 不是访问密钥。每条新消息使用不同值；网络失败重试同一条消息时复用原值，可避免 AI 重复执行。

常见响应

  • 401 invalid_access_key：密钥缺失、错误或已删除。
  • 403 access_key_scope_mismatch：目标超出密钥绑定范围。
  • 429 rate_limit_exceeded：该密钥最近 60 秒的请求次数达到 RPM。提交与查询均计数，按响应头 Retry-After 稍后重试。
  • 400 alias_requires_bound_session：密钥尚未绑定具体会话。
  • 404 target_alias_not_found：alias 与该密钥名称不符。
  • 400 invalid_target：alias 与显式目标混用。
  • 409 ambiguous_project：项目重名，使用返回的完整路径。
  • 409 ambiguous_session：会话重名，使用返回的会话 ID。
  • 503 device_unavailable：目标设备当前不可达。
