# Codex self-drawn tool icons

Local SVG copies used by the self-drawn Codex chat UI. Keep these icons in the
repo so the dashboard does not depend on the local Codex/ChatGPT.app install,
network access, npm packages, icon fonts, or external links.

The runtime currently renders equivalent inline SVG nodes from `app.js` for
offline reliability. These files are the project-owned source copies for that
icon set.

Source family: Lucide / lucide-react 0.456.0, ISC License.
